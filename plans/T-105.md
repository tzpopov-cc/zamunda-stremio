# Plan — T-105 A stray release must not count as the show

**Task:** The season explanation counts only the show's own releases (B-006). A release whose name part is
another show ("Fire Country S02E06 Alert the Sheriff" for "Sheriff Country") must not pass the show check.
**Source:** BUGS.md B-006 — Sheriff Country S2E2 gets an empty list instead of „Няма сезон 2"; 3 of 24 episode
misses in the in-app log sample.
**Constraints:** RUNBOOK — a wrong stream is worse than an honest miss; replay before every matching change.
**Related bugs:** B-006
**Depends on:** T-104 (normalised sequel numbers feed `showNameHead`)
**Security:** not affected.

## Questions before execution

None.

## Steps

- [x] 1. Root cause: `namesAnotherShow` returns "cannot judge, keep it" whenever a name word is missing from the
      release's name part. "Fire Country S02E06 Alert the Sheriff" has "sheriff" only in the episode title, so
      it is kept for Sheriff Country — its season 2 / episode numbers then fill the "available" sets, and
      Sheriff Country S2E6 would even be served the Fire Country episode.
- [x] 2. Fix at the show check: a name word missing from the name part, while the name part carries a word of its
      own that is not neutral and not a name word ("fire"), means another show. Unchanged: a missing word that is
      a number ("1923", "Mob Psycho 100", "Henry VIII" → 8 after T-104 — the name part stops at a number), and a
      name part made only of name words and neutral words ("Spartacus.S01E01.Blood.and.Sand").
- [x] 3. Check 1 — unit, real release names: rejected for Sheriff Country: "Fire Country S02E06 Alert the
      Sheriff"; kept: "Sheriff Country S01E05", "Sheriff.Country.S01.BG.Audio", "Шерифът / Sheriff Country S01";
      kept for their shows: "Spartacus.S01E01.Blood.and.Sand" (Spartacus: Blood and Sand), "1923.S01E01" (1923),
      "Henry.VIII.S01E01" (Henry VIII), "Special.Ops.Lioness.S01E01" (Lioness), "Star.Wars.Andor.S02E01" (Andor),
      the existing Vikings / Naruto / Law and Order rejections unchanged. New server against the stub: Sheriff
      Country S2E2 → „Няма сезон 2", S1E5 → rows.
- [x] 3b. Found by the first replay (49 rows lost on "War", 7 gained): the release group "-WAR" made every
      "Peacemaker…-WAR", "Andor…-WAR" a War release (49 wrong rows in the old version), and once step 2 dropped
      them, the "words before the name" path served "Chief of War", "Bleach Thousand-Year Blood War", "Queen Love
      and War". Over the 361 ids that path is right only for Lioness ("Special.Ops.Lioness" ×11 — the show's
      former title) and wrong for Brothers (2026: "Brews.Brothers" 2020, "Ghost.Brothers") and War. Rule: with
      nothing plain, the longer-name releases stay only when they all carry the same longer name, at least twice;
      otherwise MISS, empty. Checked on the new server: War S1E1 / S2E3 and Brothers S1E1 / S2E3 → empty (old: 32,
      17, 1, 1 wrong rows); Lioness S1E1 → the same 11 rows.
- [x] 4. Check 2 — replay 361 ids old vs new: no lost row except rows of another show, each read and named.
