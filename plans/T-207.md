# Plan — T-207 A P2P pack known to lack the episode is not offered for it

**Task:** A P2P pack whose known file list lacks the episode is not offered for it (B-023).
**Source:** BUGS.md B-023 — T-203 replay: "Stranger Things S05 Vol.2 2025" (file list from itorrents: chapters 5–7)
offered for S5E1 with no file index. TorBox and Real-Debrid already give no link for such a pack (v2.6.7).

unknown (itorrents 403/404, B-008) or whose file names say nothing readable is kept as today.
