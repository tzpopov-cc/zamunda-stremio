## Journal
- Step 2 found two kinds of underscore names that read WRONG once spaced, so the task gained two guards:
  - one disc of a DVD set ("MACGYVER_S01D05_BGAUDIO", "FRIENDS_SERIES4_D1B_BGAUDIO", "HOUSE_S04D01") would become a
    season pack for every episode of that season — its few episodes are unnamed .VOB files, so no file can be
    pointed at. A disc is never offered for an episode (it still counts as the season being in the archive). The
    same guard stops the five dotted "The.Event.S01.D01.DVD5" discs, which were offered for every S1 episode
    already.
  - "Taxi_Driver_3_2025-2026_E08" (season 3, episode 8) would be read as S1E8. A bare number after the name with
    the year(s) and then "E08" now declares that season, like the anime rule "Kuroko no Basket 3 - 25".
- Found by the replay: once spaced, the anime rule read "Boruto - Naruto Next Generations 1 - 293" as S1E293 and
  dropped it for every other episode. The rule now needs a one- or two-digit episode part ("Kuroko 3 - 25" kept);
  over the 8 680 cached names it changes nothing else.
- Result: names with "_" are read like names with spaces; a DVD disc is never an episode; "Taxi Driver 3 …
  E08" is season 3. Tested 2 times — (1) all 8 680 names of the replay cache, old vs new: 23 underscore names read
  differently, each right (season packs of Blue Lights / The Wire / Star Wars Visions / My Hero Academia S8 /
  Kimetsu S01-S02, Chicago_PD_S01E02, Stranger Things S05E08, Taxi Driver S3; F1 The Movie and Stranger Things
  Vol.1/2 no longer match every episode), 5 other names (The Event DVD discs) no longer offered; 21/21 unit cases;
  (2) replay 387 ids: 9 gained (Blue Lights S2E3, The Wire S2E3, My Hero Academia S8 ×2, Taxi Driver S3E8,
  Stranger Things S5E8 ×2, S5E1 Vol.2 → T-207, Chicago PD S1E2), 13 lost — all wrong rows (Stranger Things Vol.1/2
  for seasons 1–3 ×8, The Event discs ×5); fileIdx found where there was none: The Wire S1E1 → 12, Blue Lights
  S1E1 → 3, Stranger Things S5E1 Vol.1 → 1. Short replay after the Boruto fix: Boruto S1E1 / S1E150 as before.
