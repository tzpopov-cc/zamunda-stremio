# Plan — T-401 A dead row of the right show survives a live row of a namesake

**Task:** `dropDeadP2P` hides every 0-seeder row once one row is alive. For a series the live row can be a yearless
pack of another show of the same name (MacGyver 1985 "MacGyver s01" XviD vs the 2016 episodes) and the right show's
rows (which state a year that fits the season's air years) are hidden. Keep up to 3 of them when: the request is a
series episode, no live row states a fitting year, at least one dead row does, and Cinemeta lists another series of
the same name (checked only then, cached 24 h).
**Source:** B-061. **Constraints:** no new request in the normal case (condition first, request last); a failed or
slow Cinemeta search = behave as before; rows are the request's own copies (B-057) so a flag on a row is safe.
**Related bugs:** B-025 (the yearless pack stays for both shows — nothing in its name says which).

## Steps
- [ ] 1. Mark `_yearFit` on the matched rows that state a fitting year (series with Cinemeta air years).
- [ ] 2. `namesakeSeriesExists(imdbId, meta)` — Cinemeta `catalog/series/top/search=<name>.json`, same normalized
      name, other id; cached 24 h; 2,5 s timeout; false on error.
- [ ] 3. After `attachSeeders`: `markKeepDead` sets `_keepDead` on up to 3 dead `_yearFit` rows; `dropDeadP2P` skips
      rows with it.
- [ ] 4. Checks.
